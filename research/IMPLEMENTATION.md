# Implementation contracts

Package seams agreed before parallel implementation; this file is a development guide, not a frozen public protocol. Follow CRITIQUE.md corrections.

- Module github.com/TheFellow/the-line, Go 1.24.0. Ebitengine v2.8.7, x/image v0.24.0.
- `pkg/track`: `Vec3{X,Y,Z float64}`; `Point{X,Y,Z,Width,Bank float64; Surface string}` (flat JSON, metres/degrees); `Scene{Version int; Name,Vehicle string; EntrySpeed,ExitSpeed float64; Points []Point}`. EntrySpeed and ExitSpeed are upper bounds in m/s; JSON keys entry_speed_cap and exit_speed_cap. `Sample{Position,Normal Vec3; S,Width,Bank,Grade,Grip float64; Surface string}`. Normal is plan-left unit normal. `Sample.AtOffset(offset float64) Vec3` includes bank height. `Scene.Validate() error`, `SampleRoad(scene Scene, spacing float64) ([]Sample,error)`, `Load(path string)(Scene,error)`, `Save(path string, scene Scene) error`, `Presets() []string`, `Preset(name string)(Scene,error)`, `Surfaces() []Surface`, `Surface{Name string; Grip float64}`. Add small vector methods as needed. Road has open endpoints; piecewise smooth interpolated centreline, linear width/bank, stepwise surface. Preserve source-point transition stations and reject folded ribbons. Positive bank raises left edge. Normalized JSON uses degrees for bank; all public Bank values degrees, Grade rise/run.
- `pkg/vehicle`: `Config{Name string; Mass,Power,Brake,MaxSpeed,Grip,DragArea,FrontWeight,FrontDrive,Width float64}` in SI; power watts, Brake max m/s², front fractions 0..1. `Config.Validate() error`, `Presets() []string`, `Preset(name string)(Config,error)`. `Model` interface has `Parameters() Config` and `Limits(speed,curvature,bank,grade,grip float64) Envelope`; `Envelope{Acceleration,Braking,Utilization float64; Feasible bool}`. `Config` implements Model. Positive accel/braking magnitudes; include grade/drag. Friction circle and front/rear residual driven torque limits. Document approximation and bank signs. No track import.
- `pkg/solver`: `Options{Spacing float64; Iterations int; Margin float64}`; `DefaultOptions() Options`, `Solve(scene track.Scene, model vehicle.Model, opts Options)(Result,error)`. `Node{Position track.Vec3; S,Time,Speed,Curvature,Offset,Acceleration float64}`; `Result{Nodes []Node; Road []track.Sample; Duration,CenterDuration,Length float64; Iterations int}` plus useful diagnostics allowed. `Result.At(time float64) Node` interpolates position by constant segment acceleration using exported time nodes and clamps endpoints. Bank-aware 3D path distances, signed plan curvature, forward/backward force feasibility, deterministic multiscale smooth offset search; measured improvement and baseline fallback. Strict sampled/segment road containment with vehicle-width margin; no arbitrary spline applied after solving. Clearly local optimality. All graph packages headless.
- `pkg/render`: software image renderer, uses same result for plan/elevated projected mesh, professional dark panel layout, speed-colored line and readable typography, control-point markers, animated car and telemetry. Publish API promptly to CLI owner; provide `Frame` and `PNG/GIF` output or simple image.Image API. Renderer must expose projection mapping for editor picking. Static road cached for real-time GUI; animation overlay must not regenerate all mesh rasterization each tick.
- `internal/editor`: headless transactional Scene editing, selected point, undo/redo, new/add/delete/move/attributes, load/save; validate committed changes and preserve valid prior state on error. GUI uses this same package.
- `main/gui`: Ebitengine live editor/viewer, obvious clickable buttons and keyboard shortcuts. Flags for scene/preset/vehicle/view, finite frames and capture path so actual Draw output is testable. Start playing, space pause, time scrub, 2D/3D, presets/vehicle switching; editable width/bank/z/surface, point dragging, insertion/deletion, save/load path. Async solve or solve-on-release to keep app responsive. Show errors and busy state.
- `main/cli`: flags and useful help for presets/new/validate/solve/render/animate; JSON/CSV output, custom vehicle JSON, same core and renderer. Root agent owns this, integration docs, end-to-end checks.

Ownership: domain agent owns track, vehicle, editor and tests; solver agent owns solver/tests; presentation agent owns render and main/gui/tests. Root owns go.mod/go.sum, CLI, Makefile, README, integration. Stage only owned files, and make focused commits as slices complete. Communicate any API deviation before depending on it.
